# DNN_MIT_AU_JUN2024

Deep learning notebooks: ANN, CNN and RNN.

## Contents

- `DAY1_ANN_MIT_AU`: MLP classification and single and multi layer regression (scikit-learn and Keras)
- `day 2_CNN_MIT_AU`: image basics, Fashion-MNIST and CIFAR-10
- `DAY3_RNN_NLP_basics`: tokenization, stop word removal, POS tagging, TF-IDF, LSTM sequence modelling and an RNN on Google stock prices

Open the notebooks in Jupyter or Google Colab. The csv, json and xlsx files next to them are the datasets the notebooks use.
